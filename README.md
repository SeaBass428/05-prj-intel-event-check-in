# Intel Sustainability Summit: Event Check-in App

To get started, create a new Codespace from this repo.

## Attendance persistence

Check-ins are saved in the browser's local storage, so the total attendance,
attendee names, team counts, attendee list, and progress bar remain up to date
after refreshing or reopening the page in the same browser. This data is local
to that browser and is removed if its site data is cleared; it is not shared
across devices or browsers. Names from check-ins saved by older versions cannot
be recovered, so those entries appear as "Name unavailable".
